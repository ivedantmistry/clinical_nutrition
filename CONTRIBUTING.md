By participating, you agree to our [Code of Conduct](CODE_OF_CONDUCT.md).

## How Can I Contribute?

### Reporting Bugs

- Use the **Bug Report** template
- Include steps to reproduce, expected vs actual behavior, screenshots, and environment details

### Suggesting Features / Enhancements

- Use the **Feature Request** template
- Explain the problem it solves and why it's valuable (especially for clinical/dietary constraints)

### Pull Requests

1. Fork the repo and create a feature branch (`git checkout -b feature/amazing-feature`)
2. Make your changes
3. Add/update tests where applicable
4. Ensure the code passes linting and tests
5. Open a PR with a clear title and description
